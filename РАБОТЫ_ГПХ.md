# Разработка программного обеспечения для автоматизированного учета и анализа поголовья сельскохозяйственных животных

## Состав выполненных работ

1. **Подготовка обучающих данных** — разметка видеоматериалов, полученных с использованием двух типов систем видеонаблюдения

2. **Разработка программного обеспечения системы распознавания** — создание программной модели на основе технологий машинного обучения

3. **Выполнение дообучения системы распознавания** — проведение поэтапного улучшения точности работы программного обеспечения

4. **Настройка модуля предварительной обработки изображений** — обеспечение адаптации программного обеспечения к различным условиям эксплуатации

5. **Разработка программного алгоритма автоматизированного учета** — создание программного модуля учета объектов

6. **Выполнение оптимизации программного алгоритма** — доработка программного обеспечения в целях повышения точности и надежности работы

7. **Разработка программного модуля регистрации данных** — создание модуля автоматизированной записи и хранения результатов измерений

8. **Разработка пользовательского интерфейса** — создание программного веб-интерфейса для взаимодействия пользователя с системой

9. **Выполнение интеграции с весоизмерительным оборудованием** — обеспечение программного взаимодействия с весоизмерительными системами

10. **Выполнение оптимизации производительности** — проведение работ по повышению быстродействия программного обеспечения

---

*Дата составления: 13 октября 2025 г.*
