## 🎯 ЧТО РЕАЛИЗОВАНО

### ✅ REST API для метрик

```
GET /api/metrics/current
├─ current_count: количество свиней в кадре
├─ total_weight: общий вес (кг)
├─ avg_weight: средний вес (кг)
├─ left_count: проходы слева
├─ right_count: проходы справа
├─ active_act: информация о текущем акте
└─ auto_manual: статус режима (auto/manual)

POST /api/metrics/toggle-auto-fix?enabled=true|false
└─ Переключение между автоматическим и ручным режимом

POST /api/metrics/manual-fix
└─ Ручная фиксация текущего акта
```

## 🚀 КАК ИСПОЛЬЗОВАТЬ

### 1. Открыть на смартфоне

```
http://localhost:8000/mobile
```

### 2. Видеть показатели в реальном времени

- 🐷 **Текущее кол-во свиней** - сколько свиней в кадре сейчас
- ⚖️ **Средний вес** - средний вес всех видимых свиней
- 📈 **Общий вес** - сумма всех весов
- ➕ **Всего проходов** - кол-во пересечений (слева + справа)

### 3. Режим фиксации актов

#### Вариант A: АВТО (по умолчанию)
```
✓ Включен по умолчанию
✓ Система автоматически завершает акты
✓ Основано на таймаутах (MAX_INTERVAL_SEC=30 сек)
✓ Ничего вводить не нужно
✓ Оператор просто смотрит показатели
```

#### Вариант B: РУЧНОЙ
```
1. Нажать Toggle → переключить на РУЧНОЙ
2. Когда видны все свиньи → нажать ФИКСИРОВАТЬ
3. Акт завершается, счётчик сбрасывается
4. Система готова к следующей группе
```

## 📊 API ПРИМЕРЫ

### Получить текущие метрики

```bash
curl http://localhost:8000/api/metrics/current

# Response:
{
  "stream_id": "cam101",
  "current_count": 14,
  "total_weight": 1850.5,
  "avg_weight": 132.2,
  "left_count": 25,
  "right_count": 23,
  "active_act": {
    "id": 1,
    "started_at": "2025-11-06T12:30:00",
    "duration_sec": 45.5,
    "pig_ids": [1, 2, 3, ...]
  },
  "auto_manual": "auto",
  "timestamp": "2025-11-06T12:45:30"
}
```

### Переключить режим на РУЧНОЙ

```bash
curl -X POST http://localhost:8000/api/metrics/toggle-auto-fix?enabled=false

# Response:
{
  "stream_id": "cam101",
  "auto_manual": "manual",
  "message": "Auto-fix mode disabled"
}
```

### Ручная фиксация акта

```bash
curl -X POST http://localhost:8000/api/metrics/manual-fix

# Response:
{
  "stream_id": "cam101",
  "act_fixed": {
    "id": 1,
    "started_at": "2025-11-06T12:30:00",
    "ended_at": "2025-11-06T12:45:30",
    "duration_sec": 45.5,
    "count": 48,
    "total_weight": 1850.5
  },
  "message": "Act fixed and saved"
}
```
