⚡ Быстрые решения

Попробуйте эти решения в первую очередь:

  1. Обновите страницу (Ctrl+F5 или Cmd+Shift+R)
  2. Проверьте подключение к интернету
  3. Убедитесь, что сервер запущен
  4. Очистите кэш браузера
  5. Попробуйте другой браузер (Chrome или Firefox)

📁 Проблемы с загрузкой файлов

❌ "Ошибка загрузки файла: Неизвестная ошибка"

Симптомы:

  • Файл не загружается
  • Появляется сообщение об ошибке
  • Индикатор загрузки зависает

Решения:

  1. Проверьте размер файла (максимум 500MB)
  2. Убедитесь, что формат поддерживается: .mp4, .avi, .mov, .mkv, .webm, .m4v, .flv, .wmv
  3. Проверьте свободное место на диске сервера
  4. Попробуйте загрузить файл меньшего размера
  5. Проверьте права доступа к папке uploads
⚠️ Медленная загрузка файлов

Симптомы:

  • Загрузка занимает очень много времени
  • Прогресс-бар движется медленно

Решения:

  1. Проверьте скорость интернет-соединения
  2. Закройте другие приложения, использующие сеть
  3. Попробуйте сжать видеофайл
  4. Используйте проводное подключение вместо Wi-Fi

🎥 Проблемы с воспроизведением видео

❌ Видео не воспроизводится

Симптомы:

  • Черный экран вместо видео
  • Ошибка "Не удается загрузить видео"
  • Видео зависает на первом кадре

Решения:

  1. Проверьте, что файл не поврежден
  2. Убедитесь, что формат видео поддерживается
  3. Попробуйте другой видеофайл
  4. Перезапустите сервер
  5. Проверьте логи сервера на наличие ошибок
⚠️ Низкое качество видео или задержки

Симптомы:

  • Размытое или пикселизированное изображение
  • Задержка между действиями и откликом
  • Прерывистое воспроизведение

Решения:

  1. Увеличьте качество JPEG в настройках: JPEG_QUALITY=90
  2. Уменьшите FPS для экономии ресурсов: FPS=10
  3. Переключитесь на MJPEG транспорт
  4. Закройте другие ресурсоемкие приложения

⚡ Проблемы производительности

⚠️ Высокое использование памяти

Симптомы:

  • Система работает медленно
  • Браузер "тормозит"
  • Ошибки "Out of memory"

Решения:

  1. Перезапустите браузер
  2. Закройте ненужные вкладки
  3. Уменьшите размер батча: BATCH_SIZE=4
  4. Используйте CPU вместо GPU: DEVICE=cpu
  5. Перезапустите сервер
ℹ️ Медленная обработка видео

Симптомы:

  • Долгая инициализация модели
  • Низкий FPS обработки
  • Задержка в детекции объектов

Решения:

  1. Используйте GPU если доступно: DEVICE=cuda
  2. Уменьшите размер изображения: IMG_SIZE=640
  3. Увеличьте пропуск кадров: FRAME_SKIP=5
  4. Понизьте порог уверенности: CONF_THRESHOLD=0.25

⚠️ Проблемы с WebRTC

Симптомы:

  • Видеопоток не подключается
  • Ошибки соединения WebRTC
  • Черный экран при WebRTC

Решения:

  1. Переключитесь на MJPEG транспорт
  2. Проверьте настройки брандмауэра
  3. Разрешите доступ к камере в браузере
  4. Используйте HTTPS вместо HTTP
  5. Попробуйте другой браузер

🔧 Дополнительная помощь

Если проблема не решена:

  1. Запустите полную диагностику системы
  2. Проверьте логи сервера в файле logs/app.log
  3. Откройте консоль разработчика в браузере (F12)
  4. Сделайте скриншот ошибки
  5. Обратитесь к администратору системы
