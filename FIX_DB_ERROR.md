# 🔧 Исправление ошибки БД

## Проблема

```
❌ КРИТИЧЕСКАЯ ОШИБКА: Ошибка инициализации DatabaseManager: supabase-py не установлен
❌ Приложение не может работать без базы данных
```

## Причина

По умолчанию система требует базу данных (`DB_REQUIRED=true`), но для production VM база данных не нужна - данные пишутся в локальные файлы.

## Решение

### ✅ Файл `.env` уже создан с правильными настройками!

Проверьте что в `.env` есть:
```env
DB_REQUIRED=false
```

### Если файла `.env` нет:

```bash
# Скопируйте из production конфигурации
copy .env.production .env
```

### Если ошибка сохраняется:

1. Откройте `.env`:
   ```bash
   notepad .env
   ```

2. Найдите строку:
   ```env
   DB_REQUIRED=true
   ```

3. Измените на:
   ```env
   DB_REQUIRED=false
   ```

4. Сохраните и перезапустите сервер

## Проверка

После исправления должны видеть:
```
⚠️ Ошибка инициализации DatabaseManager: supabase-py не установлен
⚠️ Приложение продолжит работу без базы данных
⚠️ Функции экспорта и статистики будут недоступны
✅ PigWeight сервер запущен на http://0.0.0.0:8000
```

Это нормально! Система работает без БД, данные пишутся в локальные файлы.

## Что работает без БД

- ✅ Детекция свиней
- ✅ Подсчёт
- ✅ Видеопоток
- ✅ WebSocket обновления
- ✅ Локальное сохранение данных

## Что НЕ работает без БД

- ❌ Экспорт в Supabase
- ❌ Облачная статистика
- ❌ Синхронизация между серверами

Но для локального использования это не критично!
