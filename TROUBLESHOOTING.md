# Устранение проблем PigWeight

## Проблемы с RTSP подключением

### Симптомы
- `av_worker timeout on open_rtsp after 15.0s`
- `Worker ping timeout`
- Повторяющиеся ошибки подключения к камере

### Решения

#### 1. Проверка доступности камеры

Проверьте RTSP URL вручную:
```bash
# С помощью ffplay (если установлен)
ffplay -rtsp_transport tcp "rtsp://your_camera_url"

# С помощью VLC
vlc "rtsp://your_camera_url"
```

#### 2. Проверка сетевого подключения

```bash
# Проверьте доступность камеры
ping camera_ip_address

# Проверьте открытые порты (обычно RTSP использует 554)
telnet camera_ip_address 554
```

#### 3. Настройка RTSP параметров

Система автоматически пробует TCP и UDP транспорт. Если проблемы сохраняются:

**Вариант A: Увеличить таймауты**
В `.env` файле:
```env
RTSP_TIMEOUT=60  # Увеличить до 60 секунд
```

**Вариант B: Использовать UDP вместо TCP**
Система автоматически переключается на UDP при неудаче TCP.

**Вариант C: Проверить учетные данные**
```
rtsp://username:password@camera_ip:554/stream
```

#### 4. Проблемы с камерой

- Убедитесь, что камера включена и работает
- Проверьте, что RTSP сервис активен на камере
- Перезагрузите камеру
- Проверьте настройки firewall

#### 5. Проблемы с сетью

- Проверьте пропускную способность сети
- Убедитесь, что нет потери пакетов
- Проверьте настройки роутера/коммутатора
- Попробуйте подключиться напрямую (без роутера)

## Проблемы с производительностью

### Симптомы
- `⏱️ Медленные кадры: delta=X.XXs`
- Система не успевает обрабатывать кадры
- Высокая загрузка GPU/CPU

### Решения

#### 1. Снижение целевого FPS

Система автоматически выбирает оптимальный профиль для вашего GPU.

Для RTX 2050 (3GB VRAM) используется профиль `RTX_OPTIMIZED`:
- TARGET_FPS: 20
- IMG_SIZE: 640
- BATCH_MAX_SIZE: 4

Если проблемы сохраняются, можно вручную установить более низкий профиль:

```bash
# В .env файле
TARGET_FPS=15
IMG_SIZE=640
BATCH_MAX_SIZE=2
```

#### 2. Оптимизация модели

```bash
# Использовать меньшее разрешение
IMG_SIZE=640  # вместо 960

# Уменьшить размер батча
BATCH_MAX_SIZE=2  # вместо 4
```

#### 3. Пропуск кадров

```bash
# Обрабатывать каждый N-й кадр
FRAME_SKIP=5  # вместо 3
```

#### 4. Мониторинг ресурсов

```bash
# Проверка использования GPU
nvidia-smi

# Проверка использования CPU
htop  # или Task Manager в Windows
```

### Решение
✅ **Исправлено автоматически**

## Рекомендации по настройке для RTX 2050

Ваша система использует **RTX 2050 (3GB VRAM)**. Оптимальные настройки:

```env
# Производительность
TARGET_FPS=20
IMG_SIZE=640
BATCH_MAX_SIZE=4
USE_HALF=true

# RTSP
RTSP_TIMEOUT=30
JPEG_QUALITY=85

# Обработка
FRAME_SKIP=3
```

## Логи и диагностика

### Включение подробных логов

```bash
# В .env файле
DEBUG=true
```

### Просмотр логов

```bash
# Последние логи
tail -f logs/app.log

# Поиск ошибок
grep ERROR logs/app.log
grep WARNING logs/app.log
```

### Диагностика RTSP

Система автоматически логирует:
- Попытки подключения (TCP/UDP)
- Успешные подключения
- Ошибки и таймауты
- Используемый транспорт

Ищите в логах:
```
📊 RTSP диагностика
✅ RTSP подключение успешно через TCP/UDP
```

## Контакты и поддержка

При сохранении проблем предоставьте:
1. Логи из `logs/app.log`
2. Информацию о системе (GPU, CPU, RAM)
3. RTSP URL (без учетных данных)
4. Описание проблемы
