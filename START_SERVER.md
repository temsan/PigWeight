# 🚀 ЗАПУСК СЕРВЕРА

## Быстрый старт

```bash
# 1. Активируйте виртуальное окружение
.venv\Scripts\activate

# 2. Запустите сервер
python main.py
```

## Что должно произойти

```

==================================================
💻 CPU: CUDA недоступен
🧠 ONNX Runtime: AzureExecutionProvider, CPUExecutionProvider
⚙️ Настройки: device=cpu, half_precision=false, target_fps=10
==================================================
⚠️ Ошибка инициализации DatabaseManager: supabase-py не установлен

```

✅ **Это нормально!** Предупреждения о БД можно игнорировать.

## Проверка

Откройте в браузере:
```
http://localhost:8000
```

Или проверьте API:
```
http://localhost:8000/api/health
```

## Если ошибка "КРИТИЧЕСКАЯ ОШИБКА: База данных"

См. `FIX_DB_ERROR.md`

Быстрое решение:
```bash
# Откройте .env
notepad .env

# Найдите и измените:
DB_REQUIRED=false

# Сохраните и перезапустите
```

## Остановка сервера

```
Ctrl+C
```
