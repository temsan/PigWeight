## 🚀 Как использовать

### Быстрый тест (без БД)

```bash
# 1. Запустить тесты
python test_integration.py

# 2. Обработать видео
python console_app.py
```

### Полный тест (с БД)

```bash
# 1. Запустить Docker
docker-compose up -d

# 2. Обработать видео с сохранением в БД
python console_app.py --video uploads/test.mp4

# 3. Проверить результаты в Supabase Studio
start http://localhost:8000
```

### Тестовый режим

```bash
# Сверка с ручными записями
python console_app.py --mode test \
  --video uploads/test.mp4 \
  --excel-reference docs/manual.xlsx
```
