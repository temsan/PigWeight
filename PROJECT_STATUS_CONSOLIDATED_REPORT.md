## 🎯 **Фоновая система журналирования - ПОЛНОСТЬЮ РЕАЛИЗОВАНА**

### Детекция и запись событий:
1. **🚶 Пересечения линий детекции** - автоматическая детекция объектов в зоне между линиями
2. **📈 Пиковые значения** - отслеживание новых максимальных количеств свиней
3. **⚡ Всплески активности** - детекция резкого роста количества за короткое время (>5 свиней за 10 сек)

### Техническая реализация:
- **Сервис**: `services/event_logger.py` - основной класс `EventLogger`
- **Интеграция**: `core/processor.py` - автоматическая обработка в `UnifiedVideoProcessor`
- **API**: `api/endpoints/events.py` - полный REST API для работы с событиями
- **UI**: `static/js/events-manager.js` + панель в интерфейсе
- **Хранение**: `records/events/` (JSONL) + `records/frames/` (JPEG кадры)

### Функции системы событий:
- ✅ **Автоматическая детекция** событий во время обработки видео
- ✅ **Сохранение кадров** для важных моментов
- ✅ **Фильтрация** по типу события и времени
- ✅ **Экспорт** в CSV/JSON форматы
- ✅ **Статистика** по каждому потоку
- ✅ **Автоматическая очистка** старых событий (>24 часов)
- ✅ **REST API** для интеграции с внешними системами

## 📁 Структура данных

### События хранятся в:
```
records/
├── events/
│   └── {stream_id}_events.jsonl  # События в JSONL формате
└── frames/
    └── evt_{timestamp}_{id}.jpg  # Кадры событий
```

### Формат события:
```json

  "confidence": 0.85,

  "metadata": {

  }

```
