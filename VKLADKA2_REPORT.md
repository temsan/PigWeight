### ✅ 3. Проверены существующие эндпоинты

**Найденные эндпоинты в `api/app.py`:**

#### Базовые:
- `GET /` - главная страница
- `GET /dashboard` - дашборд
- `GET /monitoring` - мониторинг
- `GET /api/cameras` - список камер

#### Журнал актов:
- `GET /api/journal/acts` - получение актов
- `GET /api/journal/list` - список актов
- `POST /api/journal/save` - сохранение акта
- `GET /api/journal/export` - экспорт актов
- `POST /api/journal/compare` - сверка с Excel

#### Взвешивания:
- `GET /api/weighing/logs` - логи взвешиваний
- `GET /api/weighing/stats` - статистика
- `GET /api/weighing/export` - экспорт
- `POST /api/weighing/save` - сохранение
- `POST /api/weighing/manual/save` - ручное сохранение

#### Записи (Records):
- `GET /api/records` - список записей
- `GET /api/records/{act_name}` - детали записи

#### Сверка:
- `POST /api/verification/compare` - сверка с замерами

#### Линии:
- `POST /api/lines` - установка позиций линий
- `POST /api/stream/{stream_id}/line_positions` - позиции для потока

## 🎯 Инструкции по запуску

### Шаг 1: Запустить API сервер

```bash
python -m uvicorn api.app:app --host 0.0.0.0 --port 8080 --reload
```

### Шаг 2: Проверить доступность

Открыть в браузере:
- Swagger UI: http://localhost:8080/docs
- Dashboard: http://localhost:8080/dashboard
- Monitoring: http://localhost:8080/monitoring
- **Новый Monitor**: http://localhost:8080/monitor.html

### Шаг 3: Запустить тесты

```bash
# Полное тестирование
python test_api_full.py

# Базовое тестирование
python scripts/tests/test_api_endpoints.py
```

### Шаг 4: Проверить эндпоинты вручную

```bash
# Health check
curl http://localhost:8080/health

# Статистика
curl http://localhost:8080/api/weighing/stats

# Акты
curl http://localhost:8080/api/journal/acts

# Записи
curl http://localhost:8080/api/records
```
