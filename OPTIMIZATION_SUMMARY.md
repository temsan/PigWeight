## 🎛️ Новые возможности

### **Методы предобработки:**
- `adaptive` - автоматический выбор (рекомендуется)
- `center_crop` - принудительный center crop для максимального соответствия
- `letterbox` - старый метод для совместимости

### **Новые параметры конфигурации:**
```env
USE_OPTIMIZED_PREPROCESSING=true   # Включить оптимизацию
PREPROCESSING_METHOD=adaptive      # Метод предобработки
ANTI_LETTERBOX=false              # Отключить для избежания конфликтов
```
