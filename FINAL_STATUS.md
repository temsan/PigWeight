**Что сделано:**

- ✅ Автоматическая нормализация данных из разных форматов

- ✅ Генерация HTML отчетов с визуализацией
- ✅ Автоматические рекомендации

**API Endpoints:**
```
GET /api/validation/excel/parse          - парсинг Excel файла
GET /api/validation/excel/compare        - сверка с журналом
GET /api/validation/excel/report         - детальный отчет (JSON/HTML)
```

**Параметры:**
- `stream_id` - ID потока для сверки
- `excel_path` - путь к Excel файлу
- `tolerance_minutes` - допуск по времени (по умолчанию 5 минут)
- `format` - формат отчета (json/html)

**Файлы:**
- `services/excel_validator.py` - основной сервис
- `api/endpoints/validation.py` - API endpoints
