## 🔴 АРХИТЕКТУРНАЯ ПРОБЛЕМА

### Корень проблемы: Расхождение между планом и реализацией

```
Дизайн (.kiro/specs) определил:          Текущая реализация:
┌─────────────────────────────┐          ┌──────────────────────────┐
│ REST API структура          │          │ Эндпоинты /api/events/   │
│ GET /api/stats/current      │          │ GET /api/events/{id}     │
│ GET /api/acts?start_date    │    ❌    │ GET /api/events/{id}/... │
│ POST /api/export/excel      │          │ Хаотичная структура      │
│ POST /api/compare/excel     │          │                          │
│ GET /api/videos             │          │                          │
└─────────────────────────────┘          └──────────────────────────┘
```

**Следствие:** Frontend вызывает несуществующие endpoints → 404 errors

**Решение:** Реф факторинг API согласно `.kiro/specs/design.md`
