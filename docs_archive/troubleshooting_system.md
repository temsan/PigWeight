# Система диагностики и устранения неполадок

## Обзор

Система диагностики PigWeight предоставляет комплексные инструменты для выявления и решения проблем, включая автоматическую диагностику, руководства по устранению неполадок и проверку совместимости браузеров.

## Компоненты системы

### 1. API Endpoints диагностики

#### `/api/diagnostics` - Полная диагностика
Выполняет комплексную проверку системы:
- Совместимость браузера
- Системные ресурсы (память, диск, CPU)
- Зависимости Python
- Файлы моделей
- Генерация рекомендаций

#### `/api/diagnostics/quick` - Быстрая проверка
Выполняет базовую проверку критических компонентов:
- Использование памяти
- Свободное место на диске
- Наличие файлов моделей

#### `/api/diagnostics/browser-test` - Тест браузера
Проверяет совместимость текущего браузера:
- Поддержка WebRTC
- Совместимость с приложением
- Рекомендации по оптимизации

### 2. Веб-интерфейсы

#### Страница диагностики (`/static/diagnostics.html`)
- Интерактивная диагностика с визуализацией
- Автоматический запуск при загрузке
- Детальные результаты с рекомендациями

#### Руководство по устранению неполадок (`/static/troubleshooting.html`)
- Структурированное руководство по решению проблем
- Быстрые решения для частых проблем
- Таблица совместимости браузеров
- Пошаговые инструкции

### 3. Интеграция в основной интерфейс

#### Кнопка диагностики в toolbar
- Быстрый доступ к диагностике

## Функциональность

### Проверка системных ресурсов

```python
def check_system_resources():
    memory = psutil.virtual_memory()
    disk = psutil.disk_usage('/')
    cpu_percent = psutil.cpu_percent(interval=1)
    
    return {
        "memory": {
            "percent_used": memory.percent,
            "status": "ok" if memory.percent < 80 else "warning"
        },
        "disk": {
            "free_gb": round(disk.free / (1024**3), 2),
            "status": "ok" if disk.free > 1024**3 else "critical"
        },
        "cpu": {
            "percent_used": cpu_percent,
            "status": "ok" if cpu_percent < 70 else "warning"
        }
    }
```

### Проверка совместимости браузера

```python
def check_browser_compatibility(user_agent):
    compatibility = {"supported": True, "warnings": []}
    
    if "msie" in user_agent.lower():
        compatibility["supported"] = False
        compatibility["warnings"].append("Internet Explorer не поддерживается")
    
    if "chrome" in user_agent.lower():
        compatibility["webrtc_support"] = "excellent"
    elif "safari" in user_agent.lower():
        compatibility["webrtc_support"] = "limited"
    
    return compatibility
```

### Генерация рекомендаций

Система автоматически анализирует результаты диагностики и генерирует персонализированные рекомендации:

- **Критические проблемы**: Требуют немедленного внимания
- **Предупреждения**: Могут влиять на производительность
- **Информационные**: Рекомендации по оптимизации

## Типы проблем и решения

### 1. Проблемы загрузки файлов

**Симптомы:**
- "Ошибка загрузки файла: Неизвестная ошибка"
- Зависание индикатора загрузки
- Медленная загрузка

**Автоматическая диагностика:**
- Проверка размера файла (лимит 500MB)
- Валидация формата файла
- Проверка свободного места на диске
- Проверка прав доступа

**Решения:**
- Уменьшение размера файла
- Конвертация в поддерживаемый формат
- Освобождение места на диске

### 2. Проблемы производительности

**Симптомы:**
- Высокое использование памяти/CPU
- Медленная обработка видео
- Задержки в интерфейсе

**Автоматическая диагностика:**
- Мониторинг системных ресурсов
- Проверка конфигурации модели
- Анализ настроек производительности

**Решения:**
- Оптимизация параметров модели
- Переключение на CPU/GPU
- Настройка батчинга

### 3. Проблемы совместимости

**Симптомы:**
- Проблемы с WebRTC
- Некорректное отображение
- Ошибки JavaScript

**Автоматическая диагностика:**
- Определение браузера и версии
- Проверка поддержки WebRTC
- Анализ User-Agent

**Решения:**
- Переключение на MJPEG
- Обновление браузера
- Использование альтернативного браузера

## Расширение системы

1. Создайте функцию проверки в `diagnostics.py`
2. Добавьте её в `run_diagnostics()`
3. Обновите генератор рекомендаций
4. Добавьте соответствующий раздел в руководство
