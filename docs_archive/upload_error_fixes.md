# Исправления ошибок загрузки файлов

## Обзор

Исправлены критические ошибки, которые вызывали проблемы с загрузкой файлов и запуском потоков в системе PigWeight.

## Исправленные проблемы

### 1. ✅ CONFIG.get() AttributeError

**Проблема**: `'Config' object has no attribute 'get'` в core/processor.py

**Причина**: Объект CONFIG не имеет метода `get()`, но код пытался его использовать

**Исправление**:
```python
# Было:
conf_threshold=CONFIG.get("CONF_THRESHOLD", 0.3)

# Стало:
conf_threshold=getattr(CONFIG, "CONF_THRESHOLD", 0.3)
```

**Затронутые файлы**:
- `core/processor.py` - исправлены все использования CONFIG.get()

### 2. ✅ FileStream._infer_loop AttributeError

**Проблема**: `'FileStream' object has no attribute '_infer_loop'`

**Причина**: Базовый класс VideoStream не имел метода `_infer_loop`, но он вызывался в методе `start()`

**Исправление**:
```python
# Добавлен недостающий метод в VideoStream
async def _infer_loop(self):
    """Inference loop for processing frames"""
    return await _global_infer_loop(self)
```

**Результат**: Все наследники VideoStream (FileStream, RtspStream, DemoStream) теперь имеют корректный inference loop
