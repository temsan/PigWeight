### 3. Исправлена логика выбора источника

#### console_app.py (метод select_source_interactive)

**Было:**
```python
def select_source_interactive(self) -> Optional[dict]:
    # Всегда используем Rich вместо questionary для Windows совместимости
    if HAVE_RICH:
        return self._select_source_rich()  # ← Показывал таблицу!
    else:
        return self._select_source_simple()
```

**Стало:**
```python
def select_source_interactive(self) -> Optional[dict]:
    # Приоритет: questionary (стрелки) > Rich (таблица) > simple (текст)
    if HAVE_QUESTIONARY:
        return self._select_source_questionary()  # ← Стрелки!
    elif HAVE_RICH:
        return self._select_source_rich()  # Fallback: таблица
    else:
        return self._select_source_simple()  # Fallback: текст
```
