## 🔴 КРИТИЧЕСКИЕ ПРЕПЯТСТВИЯ (блокируют production)

### 1. API Standardization - Несоответствие спецификациям

**Проблема:**
Frontend запрашивает endpoints, которые не соответствуют specs:

| Текущий | Нужен по specs | Статус |
|---------|----------------|--------|
| `/api/metrics/current` | `/api/stats/current` | ❌ Не соответствует |
| Нет | `/api/weighing/acts` | ❌ Отсутствует |
| Нет | `/api/weighing/stats` | ❌ Отсутствует |
| Нет | `/api/export/excel` | ❌ Отсутствует |
| Нет | `/api/compare/excel` | ❌ Отсутствует |

**Последствия:**
- Frontend получает 404 ошибки
- Нет единого источника истины
- Невозможен экспорт/сверка через веб

**Решение:** Задача 11 - API Standardization (~3-4 часа)
- См. `.kiro/SYNC_PLAN.md` - Phase 1

**Приоритет:** 🔴 КРИТИЧЕСКИЙ

---

### 2. STREAM_MANAGER vs DatabaseManager

**Проблема:**
API endpoints используют `STREAM_MANAGER` (in-memory) вместо `DatabaseManager` (PostgreSQL):

```python
# api/endpoints/metrics.py
from api.app import STREAM_MANAGER  # ❌ Временное хранилище

# Должно быть:
from pig_tracking.database_manager import DatabaseManager  # ✅ Постоянное
```

**Последствия:**
- Данные теряются при перезапуске
- Нет истории актов
- Невозможен экспорт в Excel
- Мобильный дашборд показывает неполные данные

**Решение:** Задача 2 - Интеграция API с БД (~2-3 часа)

**Приоритет:** 🔴 КРИТИЧЕСКИЙ

## 🟡 ВЫСОКИЙ ПРИОРИТЕТ (стабильность)

### 3. WebSocket оптимизация

**Проблема:**
- Нет ограничения частоты отправки кадров
- Нет лимита подключенных клиентов
- Возможна перегрузка сети и DoS

**Решение:** Задача 9 - WebSocket оптимизация (~2 часа)
- Throttling до 10 fps максимум
- Лимит 5 одновременных клиентов
- Мониторинг метрик

**Приоритет:** 🟡 ВЫСОКИЙ

---

### 4. av_worker устойчивость

**Проблема:**
- Зависания при подключении к RTSP
- Нет таймаутов для операций
- Нет retry логики
- Worker процесс может "умереть" без восстановления

**Решение:** Задача 10 - av_worker устойчивость (~2 часа)
- Таймауты: open_rtsp (10s), read_jpeg (2s), ping (1s)
- Retry с exponential backoff (3 попытки)
- Health check каждые 30 секунд
- Автоматический перезапуск при сбое

**Приоритет:** 🟡 ВЫСОКИЙ
