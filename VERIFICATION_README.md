# Система Журналирования и Верификации Актов Взвешивания

## Обзор

Система предназначена для журналирования актов взвешивания свиней с автоматической верификацией соответствия счетчиков слева/справа и анализом файлов с замерами.

## Основные возможности

### 1. Журналирование актов взвешивания
- Автоматическое сохранение данных о каждом акте взвешивания
- Запись счетчиков входов слева и справа
- Сохранение timeline с динамикой количества свиней
- Генерация отчетов в форматах JSON, SVG и Markdown

### 2. Верификация счетчиков
- Автоматическая проверка соответствия счетчиков слева/справа
- Настраиваемая погрешность (по умолчанию 10%)
- Анализ отклонений и их классификация
- Выявление систематических ошибок

### 3. Анализ прохождения через рамки
- Отслеживание пересечений вертикальных линий
- Анализ скорости движения свиней
- Выявление пиковых периодов активности
- Статистика среднего времени между пересечениями

### 4. Анализ всплесков количества
- Обнаружение аномальных всплесков в количестве свиней
- Группировка всплесков в периоды
- Анализ паттернов поведения
- Статистический анализ с использованием стандартных отклонений

### 5. Загрузка и анализ файлов с замерами
- Поддержка Excel файлов (.xlsx, .xls)
- Автоматический анализ структуры данных
- Вычисление статистических показателей
- Сравнение с данными системы

## API Endpoints

### Верификация
- `GET /api/verification/stats` - общая статистика верификации
- `GET /api/verification/verify/{act_name}` - проверка конкретного акта
- `GET /api/verification/report` - генерация отчета о несоответствиях

### Анализ файлов
- `POST /api/verification/analyze_excel` - анализ Excel файла с замерами

## Структура файлов

```
core/verification.py          # Основная логика верификации
api/app.py                    # API endpoints для верификации
static/index.html            # Обновленный интерфейс с вкладками
static/dashboard.html        # Детальный журнал актов
static/verification.html     # Специализированный интерфейс верификации
```

## Использование

### В главном интерфейсе
1. Перейдите на главную страницу системы
2. Используйте вкладки в правой панели:
   - **Live** - текущий мониторинг и ручной ввод данных
   - **Верификация** - проверка актов и статистика
   - **Анализ** - загрузка и анализ файлов с замерами

### Верификация актов
- Автоматическая проверка происходит при каждом завершении акта
- Результаты отображаются в панели верификации
- Доступна кнопка "Отчет" для генерации детального отчета

### Анализ файлов
- Перетащите Excel файл в область загрузки
- Нажмите "Анализировать" для обработки данных
- Просмотрите результаты анализа и статистику

## Алгоритмы верификации

### Проверка счетчиков
```python
# Разница между счетчиками
diff = abs(left_count - right_count)

# Относительная разница
max_count = max(left_count, right_count)
relative_diff = diff / max_count if max_count > 0 else 0

# Проверка с учетом погрешности
verified = relative_diff <= tolerance  # tolerance = 0.1 (10%)
```

### Обнаружение всплесков
```python
# Вычисление среднего и стандартного отклонения
mean_count = sum(counts) / len(counts)
variance = sum((x - mean_count) ** 2 for x in counts) / len(counts)
std_dev = variance ** 0.5

# Порог всплеска = среднее + 2*стандартное_отклонение
spike_threshold = mean_count + 2 * std_dev
```

## Настройка

### Параметры верификации
- `tolerance`: допустимая погрешность (по умолчанию 0.1 = 10%)
- `records_dir`: директория для хранения актов (по умолчанию "records")

### Переменные окружения
```bash
# Можно настроить через .env файл
VERIFICATION_TOLERANCE=0.15  # 15% погрешность
```

## Отчеты

Система генерирует следующие типы отчетов:

1. **Статистика верификации** - общая сводка по всем актам
2. **Анализ проблем** - детализация актов с расхождениями
3. **Рекомендации** - предложения по улучшению системы
4. **Анализ паттернов** - выявление закономерностей в ошибках

## Примеры использования

### Проверка акта
```javascript
fetch('/api/verification/verify/act_file_1234567890')
  .then(r => r.json())
  .then(data => {
    if (data.verification.verified) {
      console.log('Акт прошел верификацию');
    } else {
      console.log('Обнаружено расхождение:', data.verification.message);
    }
  });
```

### Генерация отчета
```javascript
fetch('/api/verification/report')
  .then(r => r.json())
  .then(report => {
    console.log('Уровень соответствия:', report.summary.verification_rate + '%');
    console.log('Рекомендации:', report.recommendations);
  });
```

## Расширение системы

Система спроектирована для легкого расширения:

1. **Дополнительные метрики** - можно добавить новые показатели анализа
2. **Интеграция с внешними системами** - API позволяет интегрировать с другими приложениями
3. **Кастомные правила верификации** - можно добавить специфические правила проверки
4. **Экспорт в другие форматы** - легко добавить новые форматы отчетов
