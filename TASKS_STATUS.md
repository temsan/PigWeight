## 🔧 Технические детали

### Доступные API endpoints:

#### События:
- `GET /api/events/{stream_id}` - список событий
  - Параметры: `event_type`, `limit`, `since`
- `GET /api/events/{stream_id}/grouped` - группировка по датам
  - Параметры: `date` (YYYY-MM-DD)
- `GET /api/events/{stream_id}/export` - экспорт
  - Параметры: `date`, `format` (json|csv)

#### Журнал взвешиваний:
- `GET /api/journal` - список актов
- `POST /api/journal/save` - сохранение акта
- `GET /api/export/weighing` - экспорт

#### Сверка с Excel:
- `GET /api/validation/excel/parse` - парсинг Excel файла
- `GET /api/validation/excel/compare` - сверка с журналом
  - Параметры: `stream_id`, `excel_path`, `tolerance_minutes`
- `GET /api/validation/excel/report` - детальный отчет
  - Параметры: `stream_id`, `excel_path`, `format` (json|html)

### Формат логов пересечений:

```
🔵 L=0.250 y=0.456 t5 ←IN (3)   # левая линия, вход, трек 5, всего 3
🔴 R=0.750 y=0.234 t5 →IN (2)   # правая линия, вход, трек 5, всего 2
🔵 L=0.250 y=0.789 t5 OUT→ (2)  # левая линия, выход, трек 5, осталось 2
🔴 R=0.750 y=0.567 t5 ←OUT (1)  # правая линия, выход, трек 5, осталось 1
```
