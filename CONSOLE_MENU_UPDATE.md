# Обновление меню консольного приложения

## Что изменено

Все интерактивные меню в `console_app.py` теперь используют **навигацию стрелками** (↑↓) с инверсным выделением через библиотеку `questionary`.

## Обновленные меню

### 1. Главное меню (выбор режима)
- ✅ Уже было со стрелками
- Режимы: Обработка / Мониторинг / Тестовый / Справка / Выход

### 2. Выбор источника видео/камеры
- ✅ **ОБНОВЛЕНО** - теперь со стрелками
- Показывает камеры и видеофайлы
- Формат: `🎥 Камера` или `📁 Файл (размер • длительность)`
- Fallback на числовой ввод если questionary недоступен

### 3. Выбор видео для мониторинга
- ✅ **ОБНОВЛЕНО** - теперь со стрелками
- Список видеофайлов с размером и длительностью
- Fallback на числовой ввод

### 4. Параметры детектирования (режим мониторинга)
- ✅ **ОБНОВЛЕНО** - теперь со стрелками
- Вопрос: "Использовать стандартные параметры?" (Yes/No)
- Если нет - выбор из списков:
  - Порог уверенности: 0.3 / 0.5 / 0.7 / 0.9
  - Минимум свиней: 1 / 2 / 3 / 5 / 10
  - Интервал: 10 / 20 / 30 / 60 / 120 секунд
- Вопрос: "Непрерывный режим?" (Yes/No)

### 5. Выбор Excel файла (тестовый режим)
- ✅ **ДОБАВЛЕНО** - новое меню со стрелками
- Показывает Excel файлы из папки `docs/`
- Формат: `📊 filename.xlsx`
- Fallback на числовой ввод

## Технические детали

### Используемые функции questionary:
- `questionary.select()` - выбор из списка со стрелками
- `questionary.confirm()` - Yes/No вопросы

### Параметры для единообразия:
```python
questionary.select(
    "Вопрос:",
    choices=choices,
    pointer="→ ",           # Стрелка-указатель
    use_shortcuts=True,     # Быстрые клавиши
    use_arrow_keys=True,    # Навигация стрелками
    use_pointers=True       # Показывать указатель
).ask()
```

### Fallback стратегия:
Если `questionary` недоступен или возникает ошибка:
1. Rich таблица + числовой ввод (если Rich доступен)
2. Простой текстовый список + числовой ввод (если Rich недоступен)
