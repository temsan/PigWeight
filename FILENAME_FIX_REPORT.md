# Отчет об исправлении искажения имен файлов

## Проблема
Имена файлов при загрузке "раздувались" из-за добавления timestamp префиксов, что искажало оригинальные названия файлов.

**Пример проблемы:**
- Оригинальное имя: `video.mp4`
- Искаженное имя: `20241224_123456_video.mp4`

## Решение
Исправлены все endpoints загрузки файлов для сохранения оригинальных имен файлов с безопасной очисткой символов и добавлением уникальных суффиксов при необходимости.

**Новый подход:**
- Оригинальное имя: `video.mp4` → `video.mp4`
- При конфликте: `video.mp4` → `video_1.mp4`, `video_2.mp4` и т.д.

## Исправленные файлы

### ✅ Активные endpoints (ИСПРАВЛЕНЫ)
1. **`api/endpoints/video.py`** - Основной endpoint для видео
2. **`api/endpoints/files.py`** - Дополнительный endpoint для файлов  
3. **`api/app_backup.py`** - Резервная копия основного приложения

### ✅ Неактивные endpoints (ИСПРАВЛЕНЫ)
4. **`api/app.py`** - Закомментированный endpoint (на случай включения)

### ℹ️ Уже закомментированные endpoints
- **`api/simple_endpoints.py`** - Полностью закомментирован, не используется

## Новая логика обработки имен файлов

```python
import re

# Очищаем имя файла от опасных символов, сохраняя структуру
safe_filename = re.sub(r'[^\w\-_\.]', '_', file.filename)

# Проверяем на конфликты и добавляем суффикс при необходимости
file_path = UPLOAD_DIR / safe_filename
if file_path.exists():
    name_part = file_path.stem
    extension = file_path.suffix
    counter = 1
    while file_path.exists():
        safe_filename = f"{name_part}_{counter}{extension}"
        file_path = UPLOAD_DIR / safe_filename
        counter += 1
```
