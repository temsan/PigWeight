# 🏗️ Переосмысление архитектуры PigWeight

## 🔍 Текущие проблемы

### 1. Фрагментация кода
- **3 разных процессора видео**: `lightweight_processor.py`, `ultra_fast_endpoints.py`, `gpu_video_processor.py`
- **Дублирование функций**: одинаковая логика в разных файлах
- **Конфликт зависимостей**: incompatible versions в requirements.txt
- **Сложность поддержки**: множество API endpoints с похожим функционалом

### 2. Производительность
- **Неэффективное использование GPU**: разные подходы к батчингу
- **Избыточные копирования данных**: между процессорами
- **Блокирующие операции**: в async event loop
- **Утечки памяти**: неочищенные кеши и объекты

### 3. Пользовательский опыт
- **Сложный интерфейс**: множество страниц и вкладок
- **Неконсистентность**: разные стили UI в разных частях
- **Медленная загрузка**: избыточные зависимости

## 🎯 Новая архитектура

### Core Principles
1. **Единый процессор** - один класс для всех типов видео обработки
2. **Адаптивная производительность** - автоматический выбор CPU/GPU
3. **Минимальные зависимости** - только необходимые пакеты
4. **Современный UI** - единый интерфейс с компонентным подходом
