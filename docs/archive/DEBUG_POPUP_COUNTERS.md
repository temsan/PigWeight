# 🐛 Отладка позиционирования всплывающих счетчиков

**Дата:** 2025-10-15  
**Проблема:** Счетчики-всплывашки отрисовываются в стороне от фактического пересечения центроида с вертикальной линией

---

## 🔍 Анализ проблемы

### Как работает система:

1. **Сервер (api/app.py):**
   - Отслеживает центроиды свиней (нормализованные координаты 0-1)
   - При пересечении линии вычисляет точную Y-координату пересечения через интерполяцию
   - Отправляет через WebSocket: `{id, side, mode, x, y, ts}`
     - `x` - позиция линии (L или R, например 0.25 или 0.75)
     - `y` - интерполированная Y-координата пересечения (0-1)

2. **Клиент (static/js/video-manager.js):**
   - Получает координаты пересечения
   - Преобразует в пиксели canvas: `baseX = rect.x + x * rect.w`, `baseY = rect.y + y * rect.h`
   - Рисует кружок на линии и всплывающий счетчик

### Потенциальные причины проблемы:

1. ❓ **Координаты не нормализованы правильно**
2. ❓ **Rect (область отрисовки) вычисляется неправильно**
3. ❓ **Интерполяция Y-координаты работает некорректно**
4. ❓ **Линии перемещены, но координаты используют старые позиции**

## 🔧 Добавленная отладка

### 1. Лог при получении пересечения:

```javascript
console.log(`🎯 Пересечение: side=${side}, mode=${mode}, x=${x.toFixed(3)}, y=${y.toFixed(3)}, text=${text}`);
```

**Что проверить:**
- Координата `x` должна совпадать с позицией линии (например, 0.25 для левой, 0.75 для правой)
- Координата `y` должна быть в диапазоне [0, 1]

### 2. Лог при отрисовке:

```javascript
console.log(`🎨 Отрисовка popup: x=${popup.x.toFixed(3)}, y=${popup.y.toFixed(3)}, baseX=${baseX.toFixed(0)}, baseY=${baseY.toFixed(0)}, rect={x:${rect.x}, y:${rect.y}, w:${rect.w}, h:${rect.h}}`);
```

**Что проверить:**
- `baseX` должен быть на позиции линии в пикселях
- `baseY` должен быть на высоте пересечения в пикселях
- `rect` должен соответствовать размерам видео

### 3. Исправлена стрелка:

**Было:**
```javascript
ctx.lineTo(baseX - 4, baseY + 8);  // Стрелка ниже кружка
ctx.lineTo(baseX + 4, baseY + 8);
```

**Стало:**
```javascript
ctx.lineTo(baseX - 4, baseY - 8);  // Стрелка выше кружка
ctx.lineTo(baseX + 4, baseY - 8);
```

## 🔍 Диагностика по логам:

### Сценарий 1: X-координата неправильная

**Лог:**
```
🎯 Пересечение: side=left, mode=enter, x=0.450, y=0.456, text=+1
```

**Проблема:** `x=0.450` вместо `x=0.250` (позиция левой линии)

**Причина:** Сервер отправляет неправильную координату X

**Решение:** Проверить `api/app.py`, строка 692:
```python
self._recent_crossings.append({"id": int(tid), "side": "left", "mode": "enter", "x": float(L), "y": float(y_at), "ts": float(now)})
```

---

### Сценарий 2: Y-координата неправильная

**Лог:**
```
🎯 Пересечение: side=left, mode=enter, x=0.250, y=0.950, text=+1
🎨 Отрисовка popup: x=0.250, y=0.950, baseX=240, baseY=912, rect={x:0, y:0, w:960, h:960}
```

**Проблема:** `y=0.950` (почти внизу экрана), но свинья пересекла линию в середине

**Причина:** Интерполяция Y-координаты работает некорректно

**Решение:** Проверить функцию `_interp_y` в `api/app.py`, строка 654

---

### Сценарий 3: Rect неправильный

**Лог:**
```
🎯 Пересечение: side=left, mode=enter, x=0.250, y=0.456, text=+1
🎨 Отрисовка popup: x=0.250, y=0.456, baseX=120, baseY=219, rect={x:0, y:0, w:480, h:480}
```

**Проблема:** `rect.w=480` вместо реального размера видео

**Причина:** Canvas имеет неправильный размер или rect вычисляется неправильно

**Решение:** Проверить вызов `drawPopupCounters(ctx, rect)` в `video-manager.js`

---

### Сценарий 4: Координаты правильные, но визуально не совпадают

**Лог:**
```
🎯 Пересечение: side=left, mode=enter, x=0.250, y=0.456, text=+1
🎨 Отрисовка popup: x=0.250, y=0.456, baseX=240, baseY=438, rect={x:0, y:0, w:960, h:960}
```

**Проблема:** Логи правильные, но визуально кружок не на линии

**Причина:** Возможно, линии отрисовываются в другом месте, чем ожидается

**Решение:** Проверить отрисовку линий в `drawOverlay()` функции

## 📊 Ожидаемые значения:

### Для стандартных позиций линий:

- **Левая линия:** `x = 0.25` (25% от ширины)
- **Правая линия:** `x = 0.75` (75% от ширины)

### Для видео 960x960:

- **Левая линия:** `baseX = 240` пикселей
- **Правая линия:** `baseX = 720` пикселей
- **Y-координата:** зависит от высоты пересечения (0-960 пикселей)
