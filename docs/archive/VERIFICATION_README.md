# Простая Система Записи Актов Взвешивания

## Обзор

Упрощенная система для записи актов взвешивания свиней и сверки с Excel файлами.

## Основные возможности

### 1. Запись актов взвешивания
- Простое сохранение: дата, время, количество, вес
- Указание камеры
- Быстрый ввод данных

### 2. Сверка с Excel файлами  
- Загрузка Excel файлов с замерами
- Простое сравнение количества и веса
- Отчет о совпадениях и расхождениях

## Использование

### Запись акта взвешивания
1. Откройте главную страницу системы
2. Введите количество свиней и общий вес
3. Нажмите "Сохранить акт"

### Сверка с Excel
1. Перейдите на вкладку "Сверка" 
2. Выберите Excel файл с замерами
3. Нажмите "Проверить" для сравнения данных

## Технические требования

- Python 3.7+
- pandas (для анализа Excel файлов)
- FastAPI
