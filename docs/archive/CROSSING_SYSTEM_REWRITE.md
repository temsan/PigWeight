```python
if prev < L <= cx:
```

### Клиент (static/js/video-manager.js):

```javascript
handleCrossings(crossings, linePositions = null) {
    crossings.forEach(crossing => {
        // Используем координаты НАПРЯМУЮ с сервера
        const x = Number(crossing.x || 0.5); // 0.25 или 0.75
        const y = Number(crossing.y || 0.5); // 0.0 - 1.0
        
        this.popupCounters.push({
            side: crossing.side,
            mode: crossing.mode,
            x: x,  // Позиция линии
            y: y,  // Высота пересечения
            text: text,
            color: color,
            startTime: now,
            duration: 1200
        });
    });
}

drawPopupCounters(ctx, rect) {
    this.popupCounters.forEach(popup => {
        // Преобразуем нормализованные координаты в пиксели
        const baseX = rect.x + popup.x * rect.w;
        const baseY = rect.y + popup.y * rect.h;
        
        // Рисуем кружок на линии
        ctx.arc(baseX, baseY, 8, 0, Math.PI * 2);
        
        // Рисуем всплывающий счетчик
        const popupY = baseY - 25 - ease * 20;
        ctx.arc(baseX, popupY, radius, 0, Math.PI * 2);
    });
    
    // Очистка завершенных анимаций
    this.popupCounters = this.popupCounters.filter(
        p => (now - p.startTime) < p.duration
    );
}
```

## 🎯 Ключевые принципы:

### 1. Координаты с сервера - источник истины

- `x` - это позиция **линии** (L или R), не центроида
- `y` - это интерполированная Y-координата **пересечения**
- Координаты нормализованы (0-1)

### 2. Никакой корректировки на клиенте

- Не проверяем `Math.abs(x - leftLineX)`
- Не перезаписываем координаты
- Используем данные напрямую

### 3. Простая формула отрисовки

```javascript
baseX = rect.x + x * rect.w
baseY = rect.y + y * rect.h
```

Где:
- `rect` - область отображения видео (с учетом `object-fit: contain`)
- `x, y` - нормализованные координаты (0-1)
- `baseX, baseY` - пиксельные координаты на canvas

3. **Загрузите видео** с пересечениями обеих линий

4. **Проверьте логи в консоли:**

   **Ожидаемый вывод для левой линии:**
   ```
   📍 Пересечение (index.html): side=left, mode=enter, x=0.250, y=0.456, text=+1
   🎯 Пересечение: side=left, mode=enter, x=0.250, y=0.456, text=+1
   ```

## 🔍 Отладка:

### Если всплывашки все еще на x=0.25:

1. **Проверьте логи сервера:**
   ```
   🔵 L=0.250 y=0.456 t5 ←IN (3) | centroid: prev=(0.200,0.450) cur=(0.300,0.460)
   🔴 R=0.750 y=0.234 t7 →IN (2) | centroid: prev=(0.800,0.230) cur=(0.700,0.240)
   ```
   - Есть ли логи с 🔴 (правая линия)?
   - Правильные ли значения R?

2. **Проверьте логи браузера:**
   ```
   📍 Пересечение (index.html): side=right, mode=enter, x=0.750, ...
   ```
   - Приходит ли `side=right`?
   - Правильный ли `x=0.750`?

3. **Проверьте WebSocket:**
   - Откройте DevTools → Network → WS → Messages
   - Найдите сообщение с `type: "count_update"`
   - Проверьте `debug.crossings` массив
   - Должны быть объекты с `side: "right"` и `x: 0.75`

### Если кружок не на линии:

1. **Проверьте rect:**
   ```
   🎨 Отрисовка: ..., baseX=240, baseY=438, rect={x:0, y:0, w:960, h:960}
   ```
   - `rect.w` должен соответствовать ширине видео
   - `baseX` должен быть `rect.x + 0.25 * rect.w` для левой линии

2. **Проверьте отрисовку линий:**
   - Линии рисуются той же формулой: `x1 = rect.x + rect.w * leftX`
   - Если линии правильные, то и всплывашки должны быть правильными
