### ✅ 2. Усиление проверки инициализации DatabaseManager

**Проблема:** Инициализация `DatabaseManager` в `api/app.py` была обёрнута в try/except, и при неудаче сервер продолжал работу без явного сбоя (silent failure)

**Решение:**
- ✅ Добавлена переменная окружения `DB_REQUIRED` (по умолчанию `true`)
- ✅ При `DB_REQUIRED=true` приложение останавливается с явной ошибкой
- ✅ При `DB_REQUIRED=false` приложение продолжает работу с предупреждением
- ✅ Добавлен метод `test_connection()` для проверки подключения
- ✅ Создан health check endpoint `/api/health` для мониторинга

**Файлы:**
- `api/app.py` - строки 1470-1510 (обновлён блок инициализации)
- `api/endpoints/metrics.py` - добавлен `/api/health` endpoint

**Пример использования:**
```bash
# Критический режим (по умолчанию) - приложение не запустится без БД
DB_REQUIRED=true python main.py

# Опциональный режим - приложение запустится без БД
DB_REQUIRED=false python main.py
```
