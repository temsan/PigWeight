```

```

**Файл:** `console_app.py`

### 2. ✅ База данных

```
✅ Локальный Supabase (Docker)
✅ Таблица weighing_acts (started_at, ended_at, counts, peak_count)
✅ Таблица crossings (act_id, direction, coordinates)
✅ Автоматические миграции
✅ Индексы и RLS политики
```

**Файлы:** 
- `docker-compose.yml`
- `supabase/migrations/`
- `pig_tracking/database.py`

---

### 3. ✅ Excel экспорт

```
✅ Чтение из БД за период
✅ Формат как шаблон
✅ Группировка по дням
✅ Правильное форматирование (даты, числа)
✅ Стили и ширины столбцов
```

**Файл:** `pig_tracking/excel_exporter.py`

---

### 4. ✅ Сверка с Excel

```
✅ Загрузка ручных записей
✅ Сравнение автоматических результатов
✅ Поиск совпадений (±5 минут)
✅ Отчёт с цветовым выделением:
   🟢 Зелёный = совпадение
   🟡 Жёлтый = расхождение <10%
   🔴 Красный = расхождение >10%
✅ Метрики точности (Recall, Precision, F1, MAE, MAPE)
```

**Файл:** `pig_tracking/excel_comparator.py`
