# План реализации

## Обзор

Этот план описывает пошаговую реализацию системы отслеживания и взвешивания свиней. Задачи разбиты на этапы с приоритетом на MVP для демонстрации.

## Этапы разработки

### 🎯 Этап 1: MVP с базой данных
**Цель:** Запустить консольное приложение на видео, обнаружить акты взвешивания, сохранить в Supabase

**Что входит:**
- Настройка локального Supabase
- Консольное приложение с обработкой видео
- Детекция и трекинг свиней (используя существующие компоненты)
- Подсчет проходов через линии
- Обнаружение актов взвешивания
- Сохранение результатов в базу данных Supabase

**Что НЕ входит:**
- Excel экспорт и сверка
- Веб-интерфейс

### 📊 Этап 2: Excel экспорт и сверка
**Цель:** Экспорт в Excel, сверка с ручными записями

**Что входит:**
- Анализ формата Excel
- Экспорт результатов в Excel
- Сверка с ручными записями и отчет
- Тестовый режим с автоматической сверкой

### 🌐 Этап 3: Веб-интерфейс
**Цель:** Мобильный веб для мониторинга показателей

**Что входит:**
- REST API для получения данных
- HTML страница с показателями
- Обновление в реальном времени
- Кнопки экспорта и сверки

  - [ ] 4.3 Игнорировать одиночные проходы

- [ ] 7. Основной цикл обработки и сохранение в базу
