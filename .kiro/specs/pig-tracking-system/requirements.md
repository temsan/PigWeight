# Требования к системе отслеживания свиней

## Обзор

Система для автоматического подсчета свиней при прохождении через весы с возможностью сверки с ручными записями Excel.

## Основные компоненты

1. **Консольное приложение** - обрабатывает видео в фоне, обнаруживает акты взвешивания
2. **База данных Supabase** - хранит результаты обработки
3. **Excel экспорт/сверка** - экспорт результатов и сравнение с ручными записями
4. **Веб-интерфейс** - мобильная страница с показателями (опционально)

## Функциональные требования

### 1. Консольное приложение

**Основная функция:** Обработка видеофайлов для обнаружения актов взвешивания свиней

**Возможности:**
- Загрузка и обработка видеофайлов
- Обнаружение свиней с помощью YOLO модели
- Отслеживание свиней между кадрами
- Подсчет проходов через вертикальные линии детекции
- Автоматическое определение начала и конца актов взвешивания
- Игнорирование одиночных проходов (менее 3 свиней)
- Сохранение результатов в базу данных
- Вывод прогресса обработки в консоль

**Параметры запуска:**
- `--video` - путь к видеофайлу
- `--mode test` - тестовый режим с автоматической сверкой
- `--excel-reference` - файл Excel для сверки (в тестовом режиме)

### 2. База данных

**Основная функция:** Хранение результатов обработки видео

**Структура данных:**
- **Акты взвешивания:** время начала/конца, количество проходов слева/справа, пиковое количество, общий/средний вес
- **Отдельные проходы:** ID свиньи, направление, время, координаты пересечения линии

**Технические требования:**
- Локальный Supabase через Docker
- Автоматическое создание таблиц при первом запуске
- Обработка ошибок подключения

### 3. Excel экспорт и сверка

**Основная функция:** Экспорт результатов в Excel и сверка с ручными записями

**Возможности экспорта:**
- Анализ структуры шаблона `docs/Замеры 20.07 по 03.09.xlsx`
- Группировка актов по дате
- Экспорт в том же формате, что и исходный файл
- Сохранение стилей и форматирования

**Возможности сверки:**
- Загрузка файла Excel с ручными записями
- Сопоставление актов по времени (с допуском ±5 минут)
- Сравнение количества проходов и веса
- Вычисление метрик точности (Recall, Precision, MAE, MAPE)
- Генерация отчета с цветовым выделением расхождений

### 4. Веб-интерфейс (опционально)

**Основная функция:** Мобильная страница для мониторинга показателей

**Возможности:**
- Отображение текущих показателей без видео
- Обновление данных в реальном времени
- Кнопки экспорта в Excel и сверки
- Адаптивный дизайн для мобильных устройств

## Технические требования

### Производительность
- Стабильная работа в фоне 24/7
- Обработка видео без деградации производительности
- Автоматическое восстановление при ошибках

### Точность
- Использование существующей YOLO модели сегментации
- Трекинг с уникальными ID для предотвращения двойного подсчета
- Cooldown между проходами одной свиньи (1 секунда)
- Точное определение направления прохода (слева/справа)

### Конфигурация
- Настраиваемые пороги для определения актов взвешивания
- Настраиваемые позиции линий детекции
- Автоматическое определение оптимального устройства (GPU/CPU)

## Алгоритм работы

### Обнаружение актов взвешивания

1. **Детекция свиней** - YOLO модель обнаруживает свиней на каждом кадре
2. **Трекинг** - SimpleTracker присваивает уникальные ID и отслеживает между кадрами
3. **Подсчет проходов** - CrossingCounter определяет пересечения вертикальных линий
4. **Определение актов** - ActDetector группирует проходы в акты взвешивания:
   - Начало акта: 3+ свиньи за короткий период
   - Конец акта: нет активности более 30 секунд
   - Игнорирование одиночных проходов

### Параметры по умолчанию

```
# Модель
CONF_THRESHOLD = 0.30
IMG_SIZE = 960
DEVICE = "auto"

# Линии детекции
LINE_LEFT_X = 0.25
LINE_RIGHT_X = 0.75
CROSS_COOLDOWN_SEC = 1.0

# Акты взвешивания
MIN_PIGS_FOR_ACT = 3
MAX_INTERVAL_SEC = 30.0
MIN_ACT_DURATION_SEC = 10.0

# Трекинг
IOU_THRESHOLD = 0.3
MAX_AGE = 30
```

## Приоритеты разработки

### Этап 1: MVP с базой данных
- Консольное приложение
- Обработка видео
- Сохранение в Supabase
- Базовое тестирование

### Этап 2: Excel функции
- Анализ формата Excel
- Экспорт результатов
- Сверка с ручными записями
- Тестовый режим

### Этап 3: Веб-интерфейс
- REST API
- Мобильная страница
- Кнопки экспорта/сверки

## Критерии успеха

1. **Функциональность:** Консольное приложение успешно обрабатывает видео и сохраняет акты в базу
2. **Точность:** Система корректно определяет акты взвешивания и игнорирует одиночные проходы
3. **Совместимость:** Экспорт в Excel полностью совместим с существующим форматом
4. **Удобство:** Простой запуск одной командой, понятный вывод результатов
5. **Надежность:** Стабильная работа без сбоев, обработка ошибок
