# Документ требований

## Введение

Система отслеживания свиней обеспечивает автоматический подсчет свиней, проходящих через весы, с возможностью сравнения результатов с ручными записями Excel. Система состоит из консольного приложения для обработки видео, базы данных для хранения результатов, модулей экспорта и сравнения с Excel, а также опционального веб-интерфейса для мониторинга.

## Глоссарий

- **СистемаОтслеживанияСвиней**: Полная автоматизированная система подсчета и взвешивания свиней
- **КонсольноеПриложение**: Приложение командной строки для обработки и анализа видео
- **АктВзвешивания**: Событие, при котором группа свиней (3 или более) проходит через весы
- **Проход**: Пересечение одной свиньей вертикальной линии детекции
- **БазаДанных**: Локальная база данных Supabase (PostgreSQL) для хранения данных системы
- **МодельYOLO**: Модель машинного обучения для детекции и сегментации свиней
- **Трекер**: Компонент, который присваивает и поддерживает уникальные ID для свиней между кадрами видео
- **ЛинияДетекции**: Вертикальная линия в кадре видео, используемая для подсчета проходов
- **ШаблонExcel**: Файл Excel, содержащий ручные записи оператора
- **Сравнение**: Процесс сопоставления автоматических результатов с ручными записями
- **ПериодОжидания**: Минимальный временной интервал между последовательными проходами одной свиньи
- **Оператор**: Пользователь, который запускает систему и проверяет результаты
- **Администратор**: Пользователь, который настраивает параметры системы

## Требования

### Требование 1: Обработка видеофайлов

**Пользовательская история:** Как Оператор, я хочу обрабатывать видеофайлы для автоматического обнаружения актов взвешивания, чтобы избежать ручного подсчета свиней.

#### Критерии приемки

1. КОГДА КонсольноеПриложение запускается с параметром --video, ТО СистемаОтслеживанияСвиней ДОЛЖНА загрузить указанный видеофайл и начать обработку кадров.

2. ПОКА СистемаОтслеживанияСвиней обрабатывает видеофайл, ТО СистемаОтслеживанияСвиней ДОЛЖНА отображать прогресс обработки в консоли с процентом выполнения и количеством обработанных кадров.

3. СистемаОтслеживанияСвиней ДОЛЖНА обнаруживать свиней в каждом кадре видео с использованием МодельYOLO с порогом уверенности 0.30 или выше.

4. СистемаОтслеживанияСвиней ДОЛЖНА присваивать уникальные идентификаторы каждой обнаруженной свинье и отслеживать их между кадрами с использованием Трекер.

5. КОГДА свинья пересекает ЛинияДетекции, ТО СистемаОтслеживанияСвиней ДОЛЖНА зарегистрировать Проход с направлением (слева или справа), временной меткой и координатами.

### Требование 2: Обнаружение актов взвешивания

**Пользовательская история:** Как Оператор, я хочу автоматически определять начало и конец актов взвешивания, чтобы проходы свиней группировались в осмысленные события.

#### Критерии приемки

1. КОГДА количество Проход достигает 3 или более за короткий период времени, ТО СистемаОтслеживанияСвиней ДОЛЖНА начать новый АктВзвешивания с записанной временной меткой начала.

2. ПОКА АктВзвешивания активен, ТО СистемаОтслеживанияСвиней ДОЛЖНА накапливать статистику по проходам слева, проходам справа, пиковому количеству свиней и общему количеству уникальных свиней.

3. КОГДА интервал без активности превышает 30 секунд, ТО СистемаОтслеживанияСвиней ДОЛЖНА завершить текущий АктВзвешивания с записанной временной меткой окончания.

4. ЕСЛИ количество Проход в группе меньше 3, ТО СистемаОтслеживанияСвиней ДОЛЖНА игнорировать эти Проход и не создавать АктВзвешивания.

5. СистемаОтслеживанияСвиней ДОЛЖНА вычислять длительность каждого АктВзвешивания как разницу между временем окончания и временем начала в секундах.

### Требование 3: Хранение данных в базе

**Пользовательская история:** Как Оператор, я хочу сохранять результаты обработки в базу данных, чтобы анализировать исторические данные и экспортировать отчеты.

#### Критерии приемки

1. СистемаОтслеживанияСвиней ДОЛЖНА подключаться к локальной БазаДанных с использованием параметров SUPABASE_URL и SUPABASE_KEY из конфигурации.

2. КОГДА АктВзвешивания завершается, ТО СистемаОтслеживанияСвиней ДОЛЖНА сохранить запись в таблицу weighing_acts с полями: started_at, ended_at, duration_sec, left_count, right_count, peak_count, stream_id, video_file.

3. КОГДА свинья пересекает ЛинияДетекции, ТО СистемаОтслеживанияСвиней ДОЛЖНА сохранить запись в таблицу crossings с полями: act_id, pig_id, direction, crossed_at, line_x, line_y.

4. ЕСЛИ БазаДанных недоступна, ТО СистемаОтслеживанияСвиней ДОЛЖНА записать ошибку в лог и продолжить обработку без сохранения данных.

5. СистемаОтслеживанияСвиней ДОЛЖНА автоматически создавать необходимые таблицы базы данных при первом запуске с использованием SQL миграций.

### Требование 4: Экспорт в Excel

**Пользовательская история:** Как Оператор, я хочу экспортировать результаты обработки в формат Excel, чтобы делиться отчетами с коллегами и руководством в привычном формате.

#### Критерии приемки

1. СистемаОтслеживанияСвиней ДОЛЖНА анализировать структуру ШаблонExcel из файла docs/Замеры 20.07 по 03.09.xlsx для определения формата столбцов и стилей.

2. КОГДА Оператор запрашивает экспорт за период времени, ТО СистемаОтслеживанияСвиней ДОЛЖНА получить АктВзвешивания из БазаДанных за указанный период времени.

3. СистемаОтслеживанияСвиней ДОЛЖНА группировать АктВзвешивания по дате и суммировать метрики (количество проходов, общий вес, средний вес) для каждого дня.

4. СистемаОтслеживанияСвиней ДОЛЖНА создавать файл Excel с той же структурой столбцов, форматированием и стилями, что и ШаблонExcel.

5. СистемаОтслеживанияСвиней ДОЛЖНА сохранять экспортированный файл в указанную директорию с именем файла, содержащим дату экспорта.

### Требование 5: Сравнение с ручными записями

**Пользовательская история:** Как Оператор, я хочу сравнивать автоматические результаты с ручными записями оператора, чтобы оценить точность системы и выявить расхождения.

#### Критерии приемки

1. КОГДА Оператор запускает режим Сравнение с параметром --excel-reference, ТО СистемаОтслеживанияСвиней ДОЛЖНА загрузить ручные записи из указанного файла Excel.

2. СистемаОтслеживанияСвиней ДОЛЖНА сопоставлять автоматические АктВзвешивания с ручными записями по дате с допуском плюс или минус 5 минут.

3. СистемаОтслеживанияСвиней ДОЛЖНА сравнивать количество проходов и вес между автоматическими и ручными записями для каждого сопоставленного АктВзвешивания.

4. СистемаОтслеживанияСвиней ДОЛЖНА вычислять метрики точности: Recall, Precision, MAE (средняя абсолютная ошибка), MAPE (средняя абсолютная процентная ошибка) и корреляция Пирсона.

5. СистемаОтслеживанияСвиней ДОЛЖНА генерировать отчет Excel с четырьмя листами: совпадения (зеленый), расхождения (желтый или красный), пропущенные автоматикой (серый) и метрики точности.

6. СистемаОтслеживанияСвиней ДОЛЖНА сохранять отчет Сравнение в директорию test_results с именем файла, содержащим дату и время выполнения.

### Требование 6: Предотвращение двойного подсчета

**Пользовательская история:** Как Оператор, я хочу избежать двойного подсчета одной и той же свиньи, чтобы получать точные результаты.

#### Критерии приемки

1. СистемаОтслеживанияСвиней ДОЛЖНА применять ПериодОжидания длительностью 1.0 секунды между последовательными Проход одной свиньи через одну и ту же ЛинияДетекции.

2. КОГДА свинья пересекает ЛинияДетекции снова в течение ПериодОжидания, ТО СистемаОтслеживанияСвиней ДОЛЖНА игнорировать Проход и не увеличивать счетчик проходов.

3. СистемаОтслеживанияСвиней ДОЛЖНА использовать уникальные идентификаторы треков из Трекер для различения разных свиней на протяжении всего видео.

4. СистемаОтслеживанияСвиней ДОЛЖНА определять направление прохода (слева направо или справа налево) на основе изменения X-координаты центроида свиньи между кадрами.

5. СистемаОтслеживанияСвиней ДОЛЖНА интерполировать Y-координату свиньи в точке пересечения ЛинияДетекции для точного определения позиции прохода.

### Требование 7: Тестовый режим работы

**Пользовательская история:** Как разработчик системы, я хочу запускать автоматическое тестирование на видеофайлах с известными результатами, чтобы оценивать точность алгоритмов.

#### Критерии приемки

1. КОГДА КонсольноеПриложение запускается с параметром --mode test, ТО СистемаОтслеживанияСвиней ДОЛЖНА активировать тестовый режим с автоматическим Сравнение результатов.

2. СистемаОтслеживанияСвиней ДОЛЖНА обработать указанный видеофайл полностью от начала до конца со всеми обнаруженными АктВзвешивания, сохраненными в БазаДанных.

3. КОГДА обработка видео завершается в тестовом режиме, ТО СистемаОтслеживанияСвиней ДОЛЖНА автоматически запустить Сравнение с файлом Excel, указанным в параметре --excel-reference.

4. СистемаОтслеживанияСвиней ДОЛЖНА выводить метрики точности в консоль: Recall, Precision, F1-score, MAE, MAPE и корреляция Пирсона.

5. СистемаОтслеживанияСвиней ДОЛЖНА сохранять результаты тестирования в директорию, указанную в параметре --output, включая отчет Сравнение и JSON файл с метриками.

### Требование 8: Конфигурирование параметров (опционально)

**Пользовательская история:** Как Администратор, я хочу настраивать параметры обработки без изменения кода, чтобы адаптировать систему под разные условия съемки.

#### Критерии приемки

1. СистемаОтслеживанияСвиней ДОЛЖНА загружать параметры конфигурации из файла .env при запуске, включая пороги детекции, позиции линий и параметры АктВзвешивания.

2. ГДЕ параметр CONF_THRESHOLD указан в конфигурации, ТО СистемаОтслеживанияСвиней ДОЛЖНА использовать это значение как минимальный порог уверенности для детекции свиней.

3. ГДЕ параметры LINE_LEFT_X и LINE_RIGHT_X указаны в конфигурации, ТО СистемаОтслеживанияСвиней ДОЛЖНА использовать эти значения для позиционирования вертикальных ЛинияДетекции.

4. ГДЕ параметры MIN_PIGS_FOR_ACT и MAX_INTERVAL_SEC указаны в конфигурации, ТО СистемаОтслеживанияСвиней ДОЛЖНА использовать эти значения для определения начала и конца АктВзвешивания.

5. СистемаОтслеживанияСвиней ДОЛЖНА автоматически определять оптимальное устройство для инференса (CUDA GPU или CPU) на основе доступного оборудования.

### Требование 9: Веб-интерфейс для мониторинга (опционально)

**Пользовательская история:** Как Оператор, я хочу просматривать текущие метрики и историю АктВзвешивания через веб-интерфейс, чтобы мониторить работу системы удаленно с мобильного устройства.

#### Критерии приемки

1. СистемаОтслеживанияСвиней ДОЛЖНА предоставлять REST API эндпоинт GET /api/weighing/acts для получения списка АктВзвешивания за указанный период времени.

2. СистемаОтслеживанияСвиней ДОЛЖНА предоставлять REST API эндпоинт GET /api/weighing/stats для получения текущей статистики: количество свиней, проходы слева, проходы справа и активный АктВзвешивания.

3. СистемаОтслеживанияСвиней ДОЛЖНА предоставлять REST API эндпоинт POST /api/weighing/export для экспорта АктВзвешивания в файл Excel с возможностью скачивания.

4. СистемаОтслеживанияСвиней ДОЛЖНА предоставлять веб-страницу с адаптивным дизайном для отображения метрик на мобильных устройствах.

5. ПОКА веб-страница открыта, ТО СистемаОтслеживанияСвиней ДОЛЖНА обновлять отображаемые данные автоматически каждые 5 секунд.
