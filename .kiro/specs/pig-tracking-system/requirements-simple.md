# Требования к системе отслеживания свиней

## Что нужно сделать

### 1. Консольное приложение
- Запускается из командной строки двумя способами:
  - С параметром: `python console_app.py --video path/to/file.mp4`
  - Без параметра: `python console_app.py` - показывает список видео из папки uploads/ и позволяет выбрать номером
- Обрабатывает видеофайл и обнаруживает свиней
- Считает проходы через две вертикальные линии (слева и справа)
- Определяет "акты взвешивания" - когда много свиней проходит подряд
- Игнорирует одиночные проходы (меньше 3 свиней)
- Сохраняет результаты в базу данных Supabase
- Показывает прогресс обработки в консоли

**Пример интерактивного выбора:**
```
$ python console_app.py

Доступные видео в папке uploads/:
1. video_2024_01_15.mp4 (2.3 GB, 01:45:30)
2. video_2024_01_16.mp4 (1.8 GB, 01:20:15)
3. test_video.mp4 (500 MB, 00:15:00)

Выберите номер видео (или 'q' для выхода): 1

Обработка video_2024_01_15.mp4...
```

### 2. База данных
- Использовать локальный Supabase через Docker
- Таблица актов взвешивания: дата начала, дата окончания, количество слева, количество справа, пиковое количество
- Таблица проходов: к какому акту относится, направление, время, координаты
- Автоматически создавать таблицы при первом запуске

### 3. Экспорт в Excel
- Читать данные из базы за выбранный период
- Создавать Excel файл в том же формате, что и существующий шаблон
- Группировать акты по дням
- Сохранять файл с правильным форматированием (даты, числа, стили)

### 4. Сверка с Excel
- Загружать Excel файл с ручными записями операторов
- Сравнивать автоматические результаты с ручными
- Находить совпадения и расхождения по времени (±5 минут допуск)
- Создавать отчет с цветовым выделением:
  - Зеленый = совпадение
  - Желтый = небольшое расхождение (<10%)
  - Красный = большое расхождение (>10%)
- Показывать статистику точности (процент совпадений)

### 5. Тестовый режим
- Запуск: `python console_app.py --mode test --video file.mp4 --excel reference.xlsx`
- Обрабатывает видео, сохраняет в базу, автоматически сверяет с Excel
- Выводит метрики точности в консоль
- Сохраняет отчет о сверке в папку test_results/

### 6. Веб-интерфейс (опционально)
- Простая HTML страница для мобильного телефона
- Показывает только цифры без видео (экономия трафика):
  - Текущее количество свиней
  - Количество проходов слева/справа
  - Общий и средний вес
- Обновляется в реальном времени
- Кнопки для экспорта в Excel и сверки

## Технические детали

### Используемые компоненты
- Существующая модель YOLO для детекции свиней
- Существующий трекер SimpleTracker
- Существующий процессор UnifiedVideoProcessor
- Параметры из конфигурации: пороги, позиции линий, размеры изображений

### Параметры
- Порог уверенности детекции: 0.30
- Размер изображения для модели: 960px
- Позиции линий: левая 0.25, правая 0.75 (от ширины кадра)
- Минимум свиней для акта: 3
- Максимальный интервал без активности: 30 секунд
- Cooldown между проходами одной свиньи: 1 секунда

### Приоритеты
1. **Этап 1:** Консольное приложение + база данных
2. **Этап 2:** Excel экспорт и сверка
3. **Этап 3:** Веб-интерфейс

## Ожидаемый результат

После завершения можно будет:
1. Запустить `python console_app.py --video test.mp4` и получить акты взвешивания в базе
2. Экспортировать результаты в Excel в нужном формате
3. Сверить с ручными записями и получить отчет о точности
4. Использовать тестовый режим для валидации системы
5. Мониторить показатели через веб-интерфейс на телефоне
