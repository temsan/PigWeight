# Система автоматического подсчета свиней

## Что делает система

Автоматически считает свиней при прохождении через весы, анализируя видеозаписи. Заменяет ручной подсчет и позволяет проверить точность операторов.

## Основные возможности

### 1. Автоматический подсчет
- Загружаете видео с камеры весов
- Система автоматически находит моменты взвешивания
- Считает сколько свиней прошло слева направо и справа налево
- Игнорирует случайные одиночные проходы
- Сохраняет результаты в базу данных

### 2. Сверка с ручными записями
- Загружаете Excel файл с записями операторов
- Система сравнивает автоматические результаты с ручными
- Показывает где есть расхождения
- Выдает процент точности подсчета
- Создает отчет с выделением ошибок

### 3. Экспорт результатов
- Выгружает данные в Excel в том же формате, что используете сейчас
- Группирует по дням
- Сохраняет все форматирование и стили

### 4. Мониторинг на телефоне
- Простая веб-страница для просмотра текущих показателей
- Работает на любом телефоне через браузер
- Показывает только цифры (экономит трафик)
- Обновляется автоматически

## Как использовать

### Обычная работа
1. Запускаете программу на компьютере
2. Выбираете видеофайл из списка
3. Ждете окончания обработки
4. Получаете результаты в базе данных

### Проверка точности
1. Запускаете в режиме тестирования
2. Указываете видео и Excel файл с ручными записями
3. Получаете отчет о совпадениях и расхождениях
4. Видите процент точности системы

### Экспорт данных
1. Выбираете период (например, за месяц)
2. Нажимаете "Экспорт в Excel"
3. Получаете файл в привычном формате

- Автоматическая обработка вместо ручного подсчета

### Повышение точности
- Исключение человеческих ошибок при подсчете

### Удобство использования
