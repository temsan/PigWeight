# 🚀 Руководство по внедрению оптимизированной предобработки

## ✅ Что было внедрено

### 1. **Новая оптимизированная предобработка**
- 📁 `core/preprocess.py` - новые алгоритмы предобработки
- 🎯 **Center crop с черными полосами** - соответствует датасету
- 🔄 **Adaptive preprocessing** - автоматический выбор метода
- 📏 **Letterbox fallback** - для совместимости

### 2. **Интеграция с системой**
- 🔧 `services/inference_worker.py` - обновлен для использования новой предобработки
- ⚙️ `api/app.py` - добавлены новые конфигурационные параметры
- 📋 `core/config.py` - обновлены дефолтные настройки

### 3. **Конфигурация**
- 📄 `config.env.example` - пример оптимизированной конфигурации
- 📚 `ENV_CONFIG.md` - обновлена документация
- 🚨 Добавлены предупреждения о конфликтах настроек

## 🎛️ Новые параметры конфигурации

```env
# Оптимизированная предобработка
PREPROCESSING_METHOD=adaptive      # Метод: adaptive, center_crop, letterbox
ANTI_LETTERBOX=false              # Отключить для избежания конфликтов
```

### Методы предобработки:

| Метод | Описание | Когда использовать |
|-------|----------|-------------------|
| `adaptive` | Автоматический выбор | **Рекомендуется** для большинства случаев |
| `center_crop` | Принудительный center crop | Для максимального соответствия датасету |
| `letterbox` | Сохранение пропорций | Для совместимости со старой логикой |

## 🔄 Как активировать

### Вариант 1: Через .env файл (Рекомендуется)
```bash
# Скопируйте пример конфигурации
cp config.env.example .env

# Или добавьте в существующий .env:
echo "PREPROCESSING_METHOD=adaptive" >> .env  
echo "ANTI_LETTERBOX=false" >> .env
```

### Вариант 2: Через переменные окружения
```bash
export PREPROCESSING_METHOD=adaptive
export ANTI_LETTERBOX=false
```

### Вариант 3: Временное тестирование
```bash
# Запуск с оптимизированной предобработкой
PREPROCESSING_METHOD=adaptive python main.py

# Запуск со старой предобработкой
```
