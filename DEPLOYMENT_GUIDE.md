## 🎯 Оптимизация для production

### Автоматическая оптимизация

Система автоматически определит что это виртуальная машина и применит профиль `VM_OPTIMIZED`:

```
🚀 Выбран оптимальный рантайм: cpu
📱 Устройство: cpu
⚡ Профиль: VM_OPTIMIZED
💡 Виртуальная машина: 2 ядер, 8GB RAM - агрессивная оптимизация
```

**Параметры профиля VM_OPTIMIZED:**
- TARGET_FPS: 8 (очень низкий для экономии CPU)
- IMG_SIZE: 480 (минимальное разрешение)
- BATCH_MAX_SIZE: 1 (без батчинга)
- FRAME_SKIP: 7 (обрабатываем каждый 7-й кадр)

### Ручная настройка

Скопируйте `.env.production` в `.env`:

```bash
copy .env.production .env
```

Или создайте `.env` вручную с оптимальными параметрами:

```env
# Минимальная конфигурация для VM
DEVICE=cpu
USE_HALF=false
TARGET_FPS=8
IMG_SIZE=480
BATCH_MAX_SIZE=1
FRAME_SKIP=7
JPEG_QUALITY=70
RTSP_TIMEOUT=60
```

## 🔧 Установка и запуск

### 1. Установка зависимостей

```bash
# Установка Python 3.11+
# Скачайте с https://www.python.org/downloads/

# Создание виртуального окружения
python -m venv .venv

# Активация
.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка конфигурации

```bash
# .env файл уже создан с оптимальными настройками!
# Проверьте содержимое:
type .env

# Важно: DB_REQUIRED=false (БД не требуется)
```

Если нужно изменить настройки:
```bash
notepad .env
```

### 3. Запуск сервера

```bash
# Активируйте виртуальное окружение
.venv\Scripts\activate

# Запустите сервер
python main.py
```

### 4. Проверка работы

Откройте в браузере:
```
http://localhost:8000
```

Проверьте API:
```
http://localhost:8000/api/health
```

## 🐛 Устранение проблем

### Проблема: Высокая загрузка CPU (>90%)

**Решение:**
1. Снизьте TARGET_FPS до 5:
   ```env
   TARGET_FPS=5
   ```

2. Увеличьте FRAME_SKIP до 10:
   ```env
   FRAME_SKIP=10
   ```

3. Уменьшите разрешение:
   ```env
   IMG_SIZE=416
   ```

### Проблема: Нехватка памяти

**Решение:**
1. Уменьшите BATCH_MAX_SIZE:
   ```env
   BATCH_MAX_SIZE=1
   ```

2. Закройте другие приложения на сервере

3. Перезапустите сервер

### Проблема: RTSP камера не подключается

**Решение:**
1. Проверьте сеть:
   ```bash
   ping 10.15.6.27
   ```

2. Увеличьте таймаут:
   ```env
   RTSP_TIMEOUT=120
   ```

3. Проверьте URL камеры:
   ```
   rtsp://username:password@ip:port/path
   ```

### Проблема: Медленная обработка кадров

**Решение:**
1. Используйте профиль VM_OPTIMIZED (автоматически)

2. Или установите вручную:
   ```env
   TARGET_FPS=5
   IMG_SIZE=416
   FRAME_SKIP=10
   ```

3. Отключите WebRTC:
   ```env
   ENABLE_WEBRTC=false
   ```

## 🔒 Безопасность

### Firewall

Откройте порт 8000:
```bash
netsh advfirewall firewall add rule name="PigWeight" dir=in action=allow protocol=TCP localport=8000
```

### HTTPS (опционально)

Для production рекомендуется использовать HTTPS через nginx или IIS.

### Аутентификация

Настройте аутентификацию в `.env`:
```env
API_KEY=your_secret_key
ENABLE_AUTH=true
```

## 📝 Автозапуск

### Windows Service

Создайте службу Windows для автозапуска:

1. Установите NSSM:
   ```bash
   # Скачайте с https://nssm.cc/download
   ```

2. Создайте службу:
   ```bash
   nssm install PigWeight "C:\path\to\.venv\Scripts\python.exe" "C:\path\to\main.py"
   nssm set PigWeight AppDirectory "C:\path\to\project"
   nssm start PigWeight
   ```

### Task Scheduler

Или используйте Task Scheduler:
1. Откройте Task Scheduler
2. Create Task → "PigWeight"
3. Trigger: At startup
4. Action: Start program → `python.exe main.py`
