## 🐛 Известные проблемы

1. **Модель YOLO:**
   - Используется стандартная модель `yolo11n-seg.pt`
   - Для продакшена нужна кастомная модель, обученная на свиньях
   - Путь к модели: `MODEL_PATH` в `.env`

2. **Тестовое видео:**
   - Простые белые эллипсы, не реальные свиньи
   - Для реального теста нужно видео `uploads/0825.mp4`

3. **База данных:**
   - Локальный Supabase (не продакшен)
   - Данные хранятся в Docker volume
